2.Why is Java platform independent?
Answer:
Java is platform independent because Java code is compiled into bytecode, which runs on the Java Virtual Machine (JVM). The JVM converts bytecode into machine code specific to the operating system.
3. What is JVM?
Answer:
JVM (Java Virtual Machine) is an engine that runs Java bytecode.
It provides:

Memory management
Security
Platform independence
